Reference

03. Anti-Patterns Library

Learn from common mistakes using working examples where the ground truth is known. Shows how errors create bias and how to fix them.

Mistakes Covered:
  • ❌ Interpreting raw logit coefficients
  • ❌ The "control variable illusion" (post-treatment bias)
  • ❌ Using ratios as dependent variables
  • ❌ Pooled OLS when fixed effects needed
  • ❌ Weak instruments (worse than OLS!)
Download Script (.do)
Diagnostics

04. Assumption Checker

Complete diagnostic workflows for major methods. Includes what to check, how to interpret the output, and what to do if assumptions fail.

  • ✓ OLS: Linearity, heteroskedasticity, multicollinearity, endogeneity
  • ✓ Panel: Strict exogeneity, serial correlation, FE vs RE
  • ✓ IV: Instrument relevance, exogeneity, weak IV tests

Moderation

05. Moderation Mastery

Implements cutting-edge guidance from Busenbark et al. (2022, ORM). Shows why interaction coefficients ≠ interaction effects. Demonstrates proper marginal effects calculation, creates clean margins plots.

  • ✓ 2-way and 3-way interactions
  • ✓ Johnson-Neyman regions of significance
  • ✓ Complete reporting template

Getting started

  1. Download the script you need (click "Download Script" buttons above)
  2. Open in Stata (16, 17, or 18)
  3. Run the script: do scriptname.do
  4. Adapt to your own data and research question

Recommended Learning Path

  1. Start with 00_regression_plain_english.do (intuition building)
  2. Use 02_method_decision_tree_v2.do (choose your method)
  3. Learn from 03_anti_patterns.do (avoid common mistakes)
  4. Master diagnostics with 04_assumption_checker.do
  5. Dive deep into specific methods as needed
