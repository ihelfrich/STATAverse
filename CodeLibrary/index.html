Running the examples

Save your current Stata work first: the worked examples clear data in memory. The method reference only prints guidance. Run the examples in a separate folder so their figures stay together. They use constructed data, apart from the bundled Stata auto example used for diagnostics.

Full Stata is required. A successful command does not establish causal identification. If a figure cannot export, the script reports the failure and leaves the graph available in Stata.
