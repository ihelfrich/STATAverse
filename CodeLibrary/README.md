# Native Stata teaching modules

Start with `00_regression_plain_english.do`, then choose the topic needed for your analysis. The browser beginner path is in `Learn/`. These scripts create teaching data and clear the dataset in memory; save current work and use a separate output folder before running them.

The 2026 student overhaul corrected inferential interpretations, the instrument simulation, classical Hausman covariance usage, panel simulation variation, marginal-effects grids and several syntax errors. Native batch receipts are in `docs/verification/stata-script-audit.json` at the repository root. The default settings of all nine scripts complete their numerical sections in the checked environment. PNG export is separately reported because this installation lacks Java. The decision guides print candidate specifications; they do not validate research designs.

`MASTER_ARCHITECTURE.md`, `INNOVATION_SUMMARY.md` and `TRANSFORMATION_SUMMARY.md` are historical design notes. Their earlier claims about production readiness or validation are not evidence for the current release.
