# STATAverse

A modular, hyperinteractive Stata and econometrics learning site designed for graduate-level
business and operations research.

## GitHub Pages
- Deploy from the `main` branch, root directory.
- `.nojekyll` is included so static assets load cleanly.

## Current sections
- `ZeroToHero/` Econometrics & Stata Zero-to-Hero intro sequence
- `STATAForBusiness/` MGTO 80430 aligned path

## Local preview
Open `index.html` directly in a browser or run a local static server.
