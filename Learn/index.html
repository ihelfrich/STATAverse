Browser practice and Stata

Practice with three synthetic datasets, a supported set of commands, ordinary numeric missing values, and linear regression with conventional or HC1 robust standard errors.

The full Stata language requires Stata. This workspace does not implement arbitrary file imports, macros, loops, factor variables, weighted estimation, clustered inference, panel estimators, merges, reshape or user-written commands. Unsupported syntax produces an error.

Browser numeric variables use double precision. Data-changing commands clear the fitted model here; rerun the regression before predicting. Histogram bins and output formatting can differ from Stata. Collinear models are rejected rather than automatically omitting variables.

A session retains up to 500 successful commands, the last 50 undo states and 100 variables. The Results view retains the last 200 entries. Graphs and regressions require absolute values no greater than 1e100. Rescale larger values. Your progress and notes are stored in this browser when storage is available. They are not uploaded. Clearing browser data removes them; export a copy you want to keep.

Continue your work in Stata

Download the original data and your do-file into the same folder. In Stata, change the working directory to that folder, then run the do-file. It imports the original CSV and repeats your successful commands.

The original CSV is the starting data. The current CSV includes your changes. Failed commands are excluded from the do-file and retained in the results download.
