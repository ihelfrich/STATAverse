            About
            
            What this is, and what it is not
                      
          
            
            
            
              Each command here is compared with installed Stata before it is
              kept. It is still a preview: the Commands list shows what runs
              here, including survey (svy:), survival
              (stset, stcox, streg) and
              Excel files (import excel,
              export excel). Community packages from SSC are not
              here. For guided lessons, use Practice.
            
            
            
            
              sysuse loads this site's teaching datasets. Stata's
              own examples, such as auto, belong to StataCorp and
              are not included.
            
            
            
            
              Nothing you type or add leaves this browser. Your do-files, map
              and added files are kept in this browser between visits, on this
              device only; the data in memory is not. Remove takes an added file
              out, and clearing this site's data in the browser removes them
              all. Files that save, export and
              log using write are listed in the Data drawer, where
              each can be saved to your computer.
            
            
            
            
              Ctrl or ⌘ + Enter runs the do-file. Add Shift to run only the
              selected lines. Ctrl or ⌘ + . stops a run, as Break does in Stata:
              what it printed stays, and the data are as they were before the
              command that was stopped. Up and Down at the command line recall
              earlier commands.
