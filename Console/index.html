            About
            
            What this is, and what it is not
                      
          
            
            
            
              Each command here is compared with installed Stata before it is
              kept. It is still a preview: survey and survival commands, Excel
              files and community packages are not here. For guided lessons, use
              Practice.
            
            
            
            
              sysuse loads this site's teaching datasets. Stata's
              own examples, such as auto, belong to StataCorp and
              are not included.
            
            
            
            
              Nothing you type or add leaves this browser. Your do-files and map
              are kept here between visits; data and added files are not.
            
            
            
            
              Ctrl or ⌘ + Enter runs the do-file. Add Shift to run only the
              selected lines. Up and Down at the command line recall earlier
              commands.
